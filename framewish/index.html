Help with Framewish, the native photo workspace previously called ImageRouter.

Current status: development preview. Public AI connection onboarding is still being completed. The local sample applies a fixed black-and-white filter; it does not follow instructions or use AI.

Start with a photo

  1. Import a photo or try the built-in sample.
  2. Type the change you want. For a cloud edit, connect a trusted private relay and select GPT Image.
  3. Review and approve sending your image and instruction to the relay and OpenAI.
  4. Compare Before and After, then choose Save or Share.

What does BYOK mean?

You bring your own provider API access and pay that provider for usage. A ChatGPT consumer subscription does not include OpenAI API credits. The current private pilot uses a tester-owned key configured in the relay’s encrypted server settings. Public customers should not need to deploy a server; that onboarding is not available in this preview.

Connection or editing failed?

Check your network connection and trusted relay address. The relay must be configured, and the provider key must have image-model access and available API billing. For a safety rejection, revise the instruction or input. For a rate limit, wait before submitting again. Cancellation may not prevent a provider charge after a request has started.

Save and history

Allow the app to add images to Photos when you choose Save. If permission is denied, use Share or change Photos access in device Settings. In Privacy, you can stop future history saves or delete existing local history. Copies already saved to Photos or shared elsewhere are separate.

Contact the developer

Framewish is developed by Saksham Goyal. For support or a privacy request, use the contact details on Saksham Goyal’s developer page. Include “Framewish” and your app version. Never send an API key, relay token, password, or personal photo in a support message.
